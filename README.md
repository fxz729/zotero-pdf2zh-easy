# Zotero PDF2zh Easy

面向 Zotero 的 PDF 翻译易用发行版：**引导安装本地引擎、后台运行、主窗口内显示进度**，保留上游高级配置与翻译流程。

这是 [fxz729 维护的独立项目](https://github.com/fxz729/zotero-pdf2zh-easy)，基于 [guaguastandup/zotero-pdf2zh](https://github.com/guaguastandup/zotero-pdf2zh)，不是上游官方发行版。感谢原作者及所有贡献者。许可证为 AGPL-3.0-or-later，见 [LICENSE](<LICENSE>)。

> **Windows x86_64 / Zotero 10.0.6** 的完整原生链条在下述基线包上通过验收；最终包另含两项前端修复，仅完成关闭 Zotero 后的替换核验，未重跑完整原生链条。其他 Zotero 版本、macOS、Linux 尚未实机验证；单页原文保留指标不代表通用翻译准确率。[CI 以 GitHub Actions 实时状态为准](https://github.com/fxz729/zotero-pdf2zh-easy/actions)。

## Easy 改了什么

- **四区设置**：API 配置、引擎安装、翻译基本选项、本机配置与脱敏诊断。
- **一次明确同意后安装**：下载独立 Python 和依赖，不要求用户手动配置系统 Python 或启动终端。启动插件本身不会自动下载安装。
- **新目录安装，验证后切换**：每次实际安装或修复都写入全新的私有候选目录，不覆盖正在使用的环境；完成依赖与导入检查、确认服务空闲后才激活。
- **窗口内进度卡片**：左下角卡片支持折叠，不再为翻译进度创建独立原生窗口；全部成功后 8 秒收起，失败信息保留供查看。
- **独立插件身份**：与原版使用不同的插件 ID、资源名称和偏好命名空间；不会自动禁用原版或删除原版配置。
- **保留翻译能力**：固定使用 `pdf2zh-next 2.9.0` 与 `BabelDOC 0.6.2`。简化配置保存不会重置已有的高级 `extraData` 和质量参数。

## 下载与安装插件

1. 在 Zotero 的“工具 → 插件”中，**手动禁用原版 Zotero PDF2zh**。不要在原版翻译任务运行时切换插件。
2. 从 [v0.1.0 发布页](https://github.com/fxz729/zotero-pdf2zh-easy/releases/tag/v0.1.0)下载 XPI，也可使用 [最新 XPI 入口](https://github.com/fxz729/zotero-pdf2zh-easy/releases/latest/download/pdf-2-zh-easy.xpi)。若入口不可用，请检查 [发布状态](https://github.com/fxz729/zotero-pdf2zh-easy/releases)及对应附件；不要把开发构建或更新 feed 当作插件安装包。
3. 在 Zotero 插件管理器中选择“从文件安装插件”，选中下载的 XPI。
4. 打开 Zotero 设置中的 **PDF2zh Easy** 页面。

目标是兼容 Zotero 7–11；清单中的声明范围不是逐版本实机验证承诺。先查看下方平台矩阵，再决定是否试用。

## 第一次使用

### 1. 填入自己的 API

新用户的 API 地址、模型名称和 Key 均为空，不附带任何个人账号或共享额度。

- 填写服务商提供的 **Base URL**、**模型名称**和 **API Key**。
- 简化表单面向 OpenAI 兼容接口；其他协议及完整参数仍可在下方原版高级编辑器中配置。
- 非回环 API 地址必须使用 HTTPS；本机回环地址允许 HTTP。地址不应包含用户名、密码、查询参数或片段。
- 点击“保存并启用 API”才会保存并切换所用服务。
- “测试 API 连接”会在再次确认后发送一条简短请求，**可能产生 API 费用**。测试成功不会自动保存表单。

已有 Key 不会填回简化表单；显示“已保存”时留空可保留原值。高级列表中 Key 使用遮罩，原高级编辑器仍可编辑实际值。

### 2. 安装翻译引擎

点击“下载安装引擎”，阅读并确认提示。首次安装会：

- 联网从 GitHub 发布资源、PyPI 等上游来源下载 uv、独立 Python 和依赖；uv 使用固定资源校验和，随后在本机执行安装及导入检查；
- 使用 Zotero profile 下本插件自己的目录，不替换系统 Python，不需要管理员权限；
- 占用可能达到 **数 GB** 的磁盘空间，耗时受网络、平台和依赖影响；
- 在新候选目录安装，失败时不切换现有活动环境，也不自动删除旧环境。

安装阶段的状态显示可能较粗，不能仅凭长时间没有细分进度就判断卡死。安装后可点击“启动并检查本地服务”，或在下一次使用/插件启动时准备已安装的服务。

**不要承诺完全离线**：首次翻译还可能下载引擎所需的模型或字体资源；调用远程 API 始终需要服务商网络访问。

### 3. 选择翻译选项

默认的 Next 引擎工作池为 **8 并发 / 4 QPS**，默认关闭术语表自动提取。可选择左右或上下双语布局。

“高吞吐”预设为 **128 并发 / 48 QPS**，只适用于配额、余额及机器资源充足的情况，可能触发 `429` 限流或增加费用。并发/QPS 不是速度或质量保证，也不表示同时翻译相同数量的 PDF。

已有配置默认选择“保持当前设置”；**只有明确保存预设才会更改对应值**。迁移来的并发、QPS 和高级质量参数不会被新用户默认值静默覆盖。仍保留上游对已退役 DeepSeek 模型别名的兼容迁移逻辑。

### 4. 在文献中开始翻译

选中带 PDF 附件的文献，在右键菜单中使用 PDF2zh Easy 的相应操作。任务提交、进度轮询及结果导入沿用原流程，进度显示在主窗口左下角。

折叠卡片不会取消任务。关闭主窗口后再打开，可恢复当前插件会话中仍在进行的任务进度；重启 Zotero 后的任务列表恢复不在此承诺范围内。

## 从原版导入本机设置

设置页检测到原版配置时，会提供“从原版导入本机设置”按钮。

- 需明确确认，复制的内容**可能包含 API 密钥**；操作仅发生在本机，不上传，也不删除旧配置。
- Easy 使用独立的偏好命名空间。导入时把服务地址切换到本插件的本地受管服务。
- 已有 Easy API 配置或已完成迁移时，不会直接覆盖它们。
- 导入后刷新简化表单和高级列表。请先检查实际选中的服务、模型和质量设置，再提交文档。

API 配置沿用上游的本地 Zotero 偏好存储方式，**不是加密保险库或系统钥匙串**。引擎生成的本地配置也可能含凭据。请勿分享整个 profile、私有运行环境目录、身份令牌或未审查的配置/日志。

## 本地服务与修复的边界

受管服务仅监听 `127.0.0.1:8891`，使用每个环境的本机身份令牌和就绪身份校验；这不是对公网开放服务的配置。

- 已安装的服务可以在后台运行；**关闭 Zotero、关闭卡片或禁用插件不等于停止服务**。
- 当前没有设置页“停止服务”按钮，也没有关闭 Zotero 时自动停止的承诺。
- 修复要求已有服务已停止，且没有运行或待启动任务。忙碌或身份无法确认时会拒绝，不强制结束任务。
- 如果服务仍在后台，请不要反复点修复，也不要批量结束 Python/uv 进程或删除运行环境。可提交脱敏诊断，请维护者协助；必要时由用户在保存工作、确认没有其他运行任务后自行重启系统，再尝试修复。
- 失败候选和旧环境可能保留以便诊断，目前不承诺自动清理或一键回滚界面。

## 排查问题与隐私

- **原版冲突**：先确认原版插件已手动禁用；Easy 不会替你修改原版状态。
- **API 失败或 429**：核对协议、Base URL、模型、余额和配额；降低并发/QPS。测试连接与完整 PDF 翻译的资源用量不同。
- **引擎未就绪**：确认已完成安装，查看状态；不要在任务运行中修复或手工清目录。
- **没有细进度**：首次下载可能较慢；当前状态显示不包含完整安装输出，不能把单元测试通过当作安装成功。
- **大 PDF 下载失败**：客户端响应有 256 MiB 大小上限及请求超时保护。该上限不是内存占用保证，超大文件可能不适合当前版本。

在设置页生成脱敏诊断，连同操作系统/架构、Zotero 版本和复现步骤提交 [Issue](https://github.com/fxz729/zotero-pdf2zh-easy/issues)。**不要提交 Key、Authorization、完整 API 配置、私有路径、服务令牌或受限文献**。日志虽有针对凭据的脱敏措施，分享前仍须自行检查。真实 API 测试和第三方翻译产生的费用及内容传输，由用户选择的服务商规则决定。
